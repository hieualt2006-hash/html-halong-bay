# Bài Thực Hành: Trang Web Giới Thiệu Vịnh Hạ Long

Bài thực hành tạo trang HTML cơ bản giới thiệu về Vịnh Hạ Long - Di sản Thiên nhiên Thế giới.

## 📋 Yêu cầu bài tập
- Tạo tệp `halong_bay.html`.
- Cấu trúc trang chuẩn HTML5 bao gồm:
  - Thẻ tiêu đề `<h1>`.
  - Các đoạn văn bản `<p>` mô tả về Vịnh Hạ Long.
  - Hình ảnh minh họa `<img>` với thuộc tính `src`, `alt`, `width`.
  - Thẻ liên kết `<a>` dẫn đến bài viết trên Wikipedia mở trong tab mới (`target="_blank"`).

## 🚀 Cách mở xem
Mở trực tiếp tệp [`halong_bay.html`](halong_bay.html) trên bất kỳ trình duyệt web nào (Chrome, Edge, Firefox,...).
